## Welcome to the healthyverse!

The **healthyverse** is a comprehensive ecosystem of R packages designed for healthcare data analysis, time-series forecasting, machine learning, and statistical modeling. Inspired by the tidyverse philosophy, all healthyverse packages work in harmony with consistent data representations and API design patterns.

## ⚡ Quick Example

```r
# Load the entire healthyverse
library(healthyverse)

# Check package versions and status
healthyverse_sitrep()

# View any conflicts
healthyverse_conflicts()

# Update packages if needed
healthyverse_update()
```

## 🎯 Key Features

- **🏥 Healthcare Focus**: Purpose-built for healthcare data analysis
- **🔄 Consistent API**: Similar design patterns across all packages
- **📊 Comprehensive**: Data cleaning to machine learning in one ecosystem
- **⚡ Efficient**: Load all packages at once with conflict notifications
- **🔍 Manageable**: Built-in tools for version checking and updates
